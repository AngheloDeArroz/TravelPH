# TravelPH

Travel PH is a static website designed to showcase the beauty, culture, and attractions of the Philippines. The website provides an engaging and informative experience for users who want to explore different destinations across the country.

Features

Destination Highlights: Detailed information about popular destinations in the Philippines.

Interactive Maps: Embedded maps to help users locate attractions.

Travel Tips & Guides: Practical advice for tourists.

Responsive Design: Works seamlessly on desktops, tablets, and mobile devices.

Search & Filter: Quickly find destinations based on region, activities, or interests.
